# LAN Chat Secure

A secure LAN-based chat and file-transfer application developed using Python and Tkinter.

## Features

- LAN user discovery
- One-to-one chat
- TCP-based communication
- Ed25519 authentication
- X25519 key exchange
- HKDF-SHA256 session-key derivation
- AES-GCM encryption
- SHA-256 file-integrity verification
